# Встроенные скиллы (mattpocock/skills)

В образ агента запечены отобранные скиллы из
[mattpocock/skills](https://github.com/mattpocock/skills) («Skills For Real
Engineers», MIT) — одного из крупнейших репозиториев агентских практик.
Они доступны боту через `/skills` и автоматически подгружаются агентом,
когда задача подходит.

## Что внутри

**Выравнивание замысла (до работы):**
- `grill-me` / `grilling` — агент допросит тебя, пока все ветки плана не
  закрыты; `grilling` — переиспользуемый примитив, `grill-me` — команда.
- `grill-with-docs` — то же + строит предметный глоссарий (`GLOSSARY.md`)
  и ADR: меньше многословия, консистентные имена в коде.
- `wait-what` — когда ответ агента «не зашёл»: переспроси, он переупакует
  объяснение понятным языком.

**Качество кода:**
- `tdd` — red-green-refactor по вертикальным срезам.
- `diagnosing-bugs` — дисциплинированный цикл отладки сложных багов.
- `code-review` — ревью диффа по двум осям: стандарты репо и соответствие
  спеке, параллельными сабагентами.

**Работа агентов с агентами:**
- `handoff` — сжать разговор в handoff-документ для следующего агента
  (как сработало при переезде в Docker).
- `writing-for-agents` — как писать документы, которые читают агенты
  (skills, AGENTS.md) — полезно и для самой доки kit'а.
- `research` — фоновое исследование по первоисточникам с цитатами,
  результат — Markdown-файл с ссылками.

## Скиллы, которые НЕ встроены (и почему)

Полный репозиторий содержит ещё оркестраторы разработки (`to-spec`,
`to-tickets`, `implement`, `wayfinder`, `triage`, `retro`, `ask-matt`...).
Они требуют первичной настройки `/setup-matt-pocock-skills` (трекер задач,
лейблы) и имеют смысл для полноценной командной разработки. Если
понадобятся — добавляются в проект через
[skills.sh](https://skills.sh/mattpocock/skills) без правки kit'а.

## Обновление набора

Скиллы запечены в образ по фиксированному SHA upstream-репозитория
(`ARG SKILLS_REF` в `opencode/Dockerfile`). Обновление — пин нового SHA
и пересборка; deps-бот пока не следит за этим репозиторием.

## Свои скиллы

Положи `<name>/SKILL.md` в глобальный каталог (`~/.config/opencode/skills/`
внутри контейнера — т.е. в образ) или в проект: `.opencode/skills/<name>/SKILL.md`.
Формат и правила: [Agent Skills в доке OpenCode](https://opencode.ai/docs/skills/).
