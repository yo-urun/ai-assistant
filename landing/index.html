Установка за несколько минут

Единственное требование — установленный Docker. Мастер сам спросит ключи и поднимет стек.

Скачайте архив

Кнопка ниже или git clone репозитория.

Установите Docker

Docker Desktop для Windows/macOS или Docker Engine для Linux — один раз.

Запустите мастер

Скрипт спросит токен бота, ключ LLM и настройки — секреты вводятся скрыто.

Пишите боту в Telegram

Готово. Логи и управление — командой docker compose.

Windows (PowerShell)

git clone https://github.com/yo-urun/ai-assistant.git
cd ai-assistant
.\install.ps1

Linux / macOS

git clone https://github.com/yo-urun/ai-assistant.git
cd ai-assistant
chmod +x install.sh
./install.sh

Для сервера есть неинтерактивный deploy.sh, готовые образы в GHCR и бэкапы — см. руководство по VPS.

Частые вопросы

Нужен ли мощный сервер?

Достаточно VPS на 2 vCPU / 2 ГБ RAM (комфортно 4 ГБ). На 1 ГБ сборка образов может не пройти — тогда используйте готовые образы из GHCR.

Нужны ли домен и открытые порты?

Нет. Бот работает через long polling, ассистент сам обращается к Telegram. Наружу открывать ничего не нужно.

Куда уходят мои данные?

Диалоги и память хранятся локально. Наружу уходят только запросы к Telegram и к выбранному вами LLM-провайдеру (и то, если используете облачную модель).

Это бесплатно?

Да, исходный код открыт (MIT). Платными являются только услуги по внедрению и поддержке — по желанию.
